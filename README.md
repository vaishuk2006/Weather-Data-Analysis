# Weather Data Analysis

## Overview
Weather Data Analysis is a Python-based project that analyzes weather data for 10 Indian cities using Pandas and Streamlit.

## Features
- Interactive weather dashboard
- Temperature, humidity, rainfall, and wind speed analysis
- City and date filters
- Charts and weather insights
- Weather data table

## Technologies Used
- Python
- Pandas
- Streamlit
- CSV

## How to Run
1. Install the required libraries:

   py -m pip install -r requirements.txt
  
2. Run the application:
 
   py -m streamlit run app.py

3. Open the local URL shown in the terminal.

## Dataset
The `weather_data.csv` file contains illustrative monthly weather data for 10 Indian cities for 2026. The values are for demonstration and are not verified historical observations.

## Conclusion
This project demonstrates how Python can be used to analyze, visualize, and compare weather data through an interactive dashboard.
